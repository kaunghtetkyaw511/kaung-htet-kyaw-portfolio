# CineScope Movie Directory

A responsive movie discovery SPA with:

- TMDB API integration through a locally stored API Read Access Token
- Trending, now-playing, top-rated, and search feeds
- Genre filtering and sorting
- Hash-based movie detail routes
- Persistent browser watchlist
- Built-in demo catalog for a key-free portfolio preview

Open `index.html` through a local static server. The app works immediately with
demo data; use the database button to connect a TMDB token.
